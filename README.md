# E-Commerce Sales & Customer Analytics using SQL

## Project Overview

This project focuses on analyzing e-commerce sales, customer behavior, product performance, and order trends using SQL.

The objective was not only to practice SQL syntax but also to understand how SQL can be used to answer practical business questions. The analysis was performed using four related datasets:

* `customers`
* `orders`
* `order_items`
* `products`

The project follows a structured approach, starting with basic data exploration and progressing to aggregations, joins, business analysis, CTEs, window functions, and views.

---

## Business Problem

An e-commerce business generates large volumes of customer, order, and product data. This data can be used to answer important questions such as:

* How much revenue has the business generated?
* Which product categories generate the most revenue?
* Who are the highest-spending customers?
* Which countries contribute the most sales?
* How many customers are repeat customers?
* What is the average order value?
* Which orders generate the highest revenue?

The purpose of this project was to answer these questions using SQL.

## Example Query

### Revenue by Product Category

```sql
SELECT
    p.category,
    SUM(oi.quantity * oi.price) AS revenue
FROM order_items oi
JOIN products p
    ON oi.product_id = p.product_id
GROUP BY p.category
ORDER BY revenue DESC;
```

This query helps identify which product categories contribute the most to overall revenue.

---

## Advanced Analysis Example

### Top 3 Products Within Each Category

```sql
WITH product_rank AS (
    SELECT
        p.category,
        p.product_name,
        SUM(oi.quantity) AS quantity_sold,
        ROW_NUMBER() OVER (
            PARTITION BY p.category
            ORDER BY SUM(oi.quantity) DESC
        ) AS product_rank
    FROM products p
    JOIN order_items oi
        ON p.product_id = oi.product_id
    GROUP BY p.category, p.product_name
)

SELECT *
FROM product_rank
WHERE product_rank <= 3;
```
